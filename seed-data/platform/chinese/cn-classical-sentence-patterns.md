# 文言文特殊句式

## 一、知识与方法

在文言文中，特殊句式是理解和翻译的关键。文言文的表达方式与现代汉语有较大的差异，掌握这些特殊句式有助于我们更好地理解古人的思想和文化。

### 判断句

判断句用于说明主语是什么或怎么样。常见的标志词有“者”“也”等。例如，“此乃英雄也”，其中“也”表明“此”是“英雄”。

### 被动句

被动句表示动作的承受者。常用“为”“被”等词。例如，“城为敌所破”，表示“城”被“敌”破坏。

### 倒装句

倒装句改变了正常的语序，以突出某个成分。常见的有宾语前置、状语后置等。例如，“甚矣，汝之不惠！”正常顺序应为“汝之不惠甚矣”。

### 省略句

省略句省略了一些成分，通常需要根据上下文补全。例如，“吾与汝皆去”，省略了“也”字，完整应为“吾与汝皆去也”。

### 宾语前置

宾语前置是将宾语提前到动词前面，通常出现在疑问句中。例如，“何以解忧？”，正常顺序应为“以何解忧？”

## 二、典型例子

1. **判断句**
   - 例句：此人者，勇者也。
   - 分析：句中“者”“也”表明这是一个判断句，意思是“这个人是勇敢的人”。

2. **被动句**
   - 例句：书为友所借。
   - 分析：“为”字表明这是一个被动句，意思是“书被朋友借走了”。

3. **倒装句**
   - 例句：甚矣，汝之不智！
   - 分析：这是一个倒装句，正常顺序应为“汝之不智甚矣”，意思是“你的不聪明真是太严重了”。

4. **省略句**
   - 例句：吾与尔同。
   - 分析：省略了“也”字，完整应为“吾与尔同也”，意思是“我和你一样”。

5. **宾语前置**
   - 例句：何事不成？
   - 分析：宾语“事”前置，正常顺序应为“不成何事？”，意思是“什么事情没有完成？”

## 三、答题模板

1. **判断句**
   - 模板：识别标志词“者”“也”，翻译时补充“是”。
   - 采分点：准确识别标志词，翻译通顺。

2. **被动句**
   - 模板：识别标志词“为”“被”，翻译时补充“被”。
   - 采分点：正确识别被动结构，补充“被”字。

3. **倒装句**
   - 模板：调整语序至正常，翻译时保持原意。
   - 采分点：正确调整语序，翻译流畅。

4. **省略句**
   - 模板：根据上下文补充省略成分。
   - 采分点：准确补全省略成分，翻译完整。

5. **宾语前置**
   - 模板：识别前置宾语，调整至正常语序。
   - 采分点：正确识别前置结构，翻译自然。

## 四、易混易错

1. **判断句和陈述句混淆**
   - 澄清：判断句有明确标志词“者”“也”，而陈述句没有。

2. **被动句和主动句混淆**
   - 澄清：被动句有“为”“被”等标志词，主动句没有。

3. **倒装句语序不清**
   - 澄清：倒装句需根据上下文调整语序，确保翻译通顺。

4. **省略句补全错误**
   - 澄清：省略句需结合上下文补全，不能随意添加。

5. **宾语前置误判**
   - 澄清：宾语前置多出现在疑问句中，需注意句子结构。
