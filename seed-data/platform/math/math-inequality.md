# 不等式与不等式组

> 学段:初中 · 学科:数学 · 由 AI 基于 2022 课标生成

> 学习目标:理解不等式基本性质,会解一元一次不等式 (组) 并在数轴上表示

## 一、核心概念

不等式是数学中用于表示两个量之间大小关系的表达式。常见的不等号有四种：大于号 $>$，小于号 $<$，大于等于号 $\geq$，小于等于号 $\leq$。与等式不同，不等式表示的是一种范围关系。

### 几何视角

在数轴上，不等式可以用区间表示。例如，$x > 3$ 表示所有大于 3 的数，在数轴上是从 3 向右延伸的部分，不包括 3。

### 代数视角

代数上，不等式可以通过代数运算求解。例如，解不等式 $2x + 3 < 7$，我们可以通过移项和除法得到 $x < 2$。

不等式组是指多个不等式的集合，通常需要同时满足这些不等式。例如，解不等式组 $\begin{cases} x + 2 > 0 \\ 2x - 3 < 5 \end{cases}$，我们需要找到同时满足这两个条件的 $x$ 值。

## 二、关键公式与性质

1. **加法性质**：如果 $a > b$，那么 $a + c > b + c$。这说明不等式两边同时加上一个数，不等式方向不变。

2. **乘法性质**：如果 $a > b$，且 $c > 0$，那么 $ac > bc$；如果 $c < 0$，那么 $ac < bc$。这说明不等式两边同时乘以一个正数，不等式方向不变；乘以一个负数，不等式方向改变。

3. **传递性**：如果 $a > b$ 且 $b > c$，那么 $a > c$。这说明不等式具有传递性。

4. **反向性**：如果 $a > b$，那么 $-a < -b$。这说明不等式两边同时取反，不等式方向改变。

## 三、典型题型与解题思路

### 题型 1: 解一元一次不等式

- **题目特征**: 包含一个未知数，通常需要通过基本代数运算求解。
- **解题主线**: 通过移项、合并同类项、系数化简等步骤，最终求出未知数的范围。

**演示题**: 解不等式 $3x - 5 \leq 10$。

**解题过程**:
1. 移项：$3x \leq 10 + 5$。
2. 化简：$3x \leq 15$。
3. 除以 3：$x \leq 5$。

### 题型 2: 解不等式组

- **题目特征**: 包含多个不等式，需同时满足。
- **解题主线**: 分别解每个不等式，然后找出解集的交集。

**演示题**: 解不等式组 $\begin{cases} x - 1 > 0 \\ 2x + 3 \leq 7 \end{cases}$。

**解题过程**:
1. 解第一个不等式：$x > 1$。
2. 解第二个不等式：$2x \leq 4 \Rightarrow x \leq 2$。
3. 找交集：$1 < x \leq 2$。

## 四、易混易错

1. **不等号方向改变**: 乘除以负数时，不要忘记改变不等号方向。
2. **解集表示**: 在数轴上表示解集时，注意开区间和闭区间的区别。
3. **解不等式组**: 常常忘记找出多个不等式解集的交集。
4. **边界值处理**: 在处理 $\geq$ 和 $\leq$ 时，注意边界值是否包含在解集中。
5. **计算错误**: 基本代数运算中易出现计算错误，需细心检查。

## 五、学习建议

学习不等式和不等式组时，建议先从简单的一元一次不等式开始，掌握基本解法和性质。然后逐步过渡到不等式组，练习同时满足多个条件的解法。在练习中，多使用数轴帮助理解解集的范围。最后，定期回顾不等式的性质和解题步骤，以巩固理解和提高熟练度。
